# OSP Watch

An early tool for machine shops that send jobs to outside processors (plating, anodize, heat
treat): a morning list of jobs that need a check, with the email drafted; an expedite ledger;
real turn times per processor.

**Early version.** The demo data is a fictional shop. Nothing is for sale.

This repo only hosts the page. It holds no shop's data: jobs a shop enters are saved in that
shop's own browser, or in a file on its own shared drive. The page makes no network calls.

`index.html` is generated; the source and its checks live in the team's private repository.
